# 광고(AdMob) 붙이기

> **이 문서는 사람이 읽습니다.** 코드를 만지는 절차는 [frontend/src/ads/README.md](../frontend/src/ads/README.md) 에 있습니다.

앱에 광고를 넣을지 정하고, 넣기로 했다면 스토어에 올리기 전에 무엇을 준비해야 하는지 적어 둔다.

## 먼저 정할 것 — 이 앱에 광고가 맞나

템플릿에는 광고 모듈이 **켜져 있지만 비어 있는 상태**로 들어 있다(단위 ID 가 비어 있어 배포 빌드에서는 아무것도 뜨지 않는다).

| 이런 앱이면 | 이렇게 |
|---|---|
| 사내 도구·관리자 화면·B2B | **지운다.** 광고를 안 쓰는데 SDK 만 남으면 스토어 고지 부담만 진다 |
| 무료 소비자 앱 | 쓴다. 배너부터 시작하고, 전면은 흐름이 끊기는 지점에만 |
| 유료·구독 앱 | 지운다. 결제한 사용자에게 광고를 보이면 평점이 떨어진다 |

지우는 절차는 다섯 단계이고 `frontend/src/ads/README.md` 마지막 절에 있다. **먼저 지우고 시작하는 편이 낫다** — 나중에 필요하면 그때 되살리면 된다.

## 쓰기로 했다면 — 준비물

1. **AdMob 계정과 앱 등록** — [admob.google.com](https://admob.google.com). 앱 ID(`~` 가 들어감)와 광고 단위 ID(`/` 가 들어감)는 다른 값이다.

2. **`app.json` 의 테스트 값 교체** — 플러그인의 `androidAppId`·`iosAppId` 는 지금 **구글 공개 테스트 앱 ID** 다. 이 상태로 스토어에 올리면 안 된다.

3. **dev client** — Expo Go 에는 광고 네이티브 모듈이 없어 실제 광고가 뜨지 않는다. `npx expo prebuild && npx expo run:android` 로 확인한다.

## 스토어에 올리기 전 체크리스트

광고 SDK 가 들어 있으면 심사에서 아래를 요구한다. 하나라도 빠지면 반려된다.

- [ ] **iOS 앱 추적 투명성(ATT)** — 맞춤 광고를 쓸 거면 `NSUserTrackingUsageDescription` 문구를 `app.json` 의 `ios.infoPlist` 에 넣는다. 안 쓸 거면 요청 코드도 넣지 않는다.

- [ ] **개인정보 처리방침 URL** — 스토어 등록 정보에 필수다. 광고 식별자 수집을 명시한다.

- [ ] **App Store 데이터 수집 신고 / Play 데이터 보안 양식** — "광고 데이터"·"기기 식별자" 항목을 체크한다.

- [ ] **아동 대상 앱이면** — 아동 대상(COPPA·GDPR-K) 설정이 따로 필요하다. 기본값으로 두면 안 된다.

- [ ] **테스트 광고로 배포하지 않았는지** — 단위 ID 를 채웠는지 확인한다. 안 채우면 배포 빌드에서는 지면이 그려지지 않게 해 뒀다(사고 방지 기본값).

- [ ] **자체 클릭 금지** — 자기 앱의 광고를 직접 누르면 계정이 정지된다. 개발 중에는 반드시 테스트 단위를 쓴다.

## 유럽 사용자가 있으면

GDPR 동의 수집(UMP SDK)이 추가로 필요하다. 템플릿에는 들어 있지 않다 — 유럽 배포 계획이 있으면
`react-native-google-mobile-ads` 의 `AdsConsent` 를 붙이고, 동의 전에는 맞춤 광고를 요청하지 않는다.
